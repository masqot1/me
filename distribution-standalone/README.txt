TrueWebsiteCloner 1.0.0 Standalone — Windows x64
================================================

This package includes the required .NET runtime inside its executables. A separate .NET 10 installation is not required.

1. Extract the ZIP to a local folder.
2. Run 01_INSTALL.bat (no administrator rights required).
3. In Chrome open chrome://extensions, enable Developer mode, Load unpacked the chrome-extension folder, and confirm ID ggcmdgdiopplpbcfinamhjdkbhiknfbk.
4. Run 02_RUN_TRUEWEBSITECLONER.bat.

CLI
---
bin\cli\TrueWebsiteCloner.Cli.exe contains offline, recovery, graph, snapshot, portable, readiness, seal and bundle commands.

Use only on websites/applications/test environments you own or are authorized to capture.
