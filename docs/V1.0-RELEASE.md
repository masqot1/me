# TrueWebsiteCloner 1.0.0

TrueWebsiteCloner 1.0.0 is the first full Windows release baseline produced by the staged PASS-gate process.

Core release capabilities include:

- Windows WPF desktop foundation and Chrome Manifest V3 Native Messaging bridge;
- real Chrome network metadata and bounded same-origin response-body capture;
- deterministic offline resource/path building;
- loopback-only recorded GET replay;
- source-vs-offline verification and controlled missing-resource recovery;
- dependency graph and weighted completeness scoring;
- source/offline visual comparison;
- immutable project snapshots and snapshot diffing;
- deterministic `.twcproj` export/import with SHA-256 integrity and safe extraction;
- bounded workspace project catalog and diagnostics model;
- deterministic release-readiness fingerprint;
- immutable verified release seal;
- deterministic `.twcrelease` release bundle with embedded portable and seal verification;
- one-command Windows verified release workflow;
- V1.0-RC1 master core-gate sweep.

The final V1.0 aggregate GitHub gate does not replace individual gates. It waits for every push-triggered `TrueWebsiteCloner` workflow present in `.github/workflows` on the exact final commit and requires each one to complete successfully.

Version: `1.0.0`
