# TrueWebsiteCloner 1.0.0 — Standalone Windows x64

The standalone distribution embeds .NET 10 into self-contained single-file executables, so the destination machine does not need a separately installed .NET runtime.

To reduce duplicated runtime payload, the former offline/recovery/graph/snapshot/portable/readiness/seal/bundle executables are also exposed through one self-contained `TrueWebsiteCloner.Cli.exe`. Desktop, Native Host, Test Lab and Local Runtime remain separate executables because they are independent processes.

The standalone gate verifies every file SHA-256, rejects debug PDBs, confirms the installer has no installed-dotnet check, builds the ZIP twice from identical self-contained binaries, and requires byte-identical archive SHA-256 values before uploading the 90-day GitHub Actions artifact.
