# Gate 0.14 — Release Readiness

Uses existing local project evidence only. It never restarts capture or contacts an external site. `_diagnostics/release-readiness.json` is READY only when diagnostics, capture bodies, offline build, zero missing resources, 100% completeness, dependency graph, replay verification, visual comparison, snapshot history, and import integrity when applicable all pass. A deterministic SHA-256 release fingerprint binds the evidence.
