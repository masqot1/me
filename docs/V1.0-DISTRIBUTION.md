# TrueWebsiteCloner 1.0.0 — Windows Distribution

The V1.0 distribution is a framework-dependent Windows x64 package produced only after the V1.0 final gate baseline.

## Contents

The package preserves the runtime layout expected by the application: `artifacts/desktop`, `artifacts/native-host`, Test Lab, Local Runtime and the offline/recovery/graph/snapshot/portable/release/seal/bundle tools. It also contains the pinned Manifest V3 Chrome extension, V1.0 release documentation, the verified release workflow script, installer/uninstaller wrappers and a per-file integrity manifest.

## Runtime requirements

The installer requires .NET 10 instances of `Microsoft.NETCore.App`, `Microsoft.WindowsDesktop.App` and `Microsoft.AspNetCore.App`. It registers Chrome Native Messaging under the current user's HKCU hive; administrator rights are not required. Chrome still requires the unpacked extension to be loaded manually in Developer mode.

## Integrity

`distribution-manifest.json` records SHA-256 and byte length for every payload file. The complete archive has a `.sha256` sidecar. The Distribution Gate builds the package twice from the same published binaries, verifies every declared file hash and requires the two ZIP SHA-256 values to be identical.

The ZIP is uploaded as the `TrueWebsiteCloner-1.0.0-win-x64` GitHub Actions artifact with 90-day retention.
